— How loops get opened & closed
The brain opens a loop when it detects a forward-looking commitment in any source — "I'll send", "we'll get back", "by Friday", "let me circle back", an issue assigned, a calendar promise. It closes a loop when it sees evidence — outbound email matching the recipient, a doc shared, a PR merged, a contract signed, an inbound thank-you. ⌕ see compile_truth runs
