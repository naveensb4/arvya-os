— Boundaries the brain respects.

Forget on disconnect
When a source is disconnected, all derived memories, edges, and entity-page sections are removed within 30 days. You can also force-purge instantly.
Personal label = invisible
Any source labelled "personal" (Gmail label, Calendar private, Slack DM) is excluded entirely. The brain never sees, indexes, or surfaces it.
Reads, never writes
By default the brain only reads. To draft replies, send messages, or update tickets, you must enable per-connector write scopes.
Audit log of every read
Every fetch, every entity touched, every model call is in ⌕ Agent runs with timestamps and source citations.
